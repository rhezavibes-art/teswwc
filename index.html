Tambah / Perbarui Data Kader

Import dari Excel / CSV Google Form

Unggah file jawaban formulir (.xlsx / .csv). Kolom NIM, Nama, dan Jurusan dibaca otomatis. Kader yang sudah ada hanya diperbarui, sesi dan status mereka tidak berubah, jadi aman diimpor berulang kali saat ada pendaftar baru.

Import Massal / Atur Sesi (Format: NIM;Nama;Jurusan;Sesi;Status — Sesi & Status boleh kosong; Nama boleh kosong untuk NIM yang sudah terdaftar)

Daftar Kader Terdaftar

Alur Update ke Netlify Agar Data Pasti Tersimpan:

1. Pastikan data kader sudah diinput di tab Data Kader.

2. Klik tombol di bawah untuk mengunduh index.html terbaru yang sudah memuat data kader dan versi penyimpanan baru.

3. Buka Netlify → Deploys → Drop new files → upload file yang namanya persis index.html (jika browser menamainya index (1).html, ganti nama dulu), lalu cek di tab Incognito.

4. Ada pendaftar baru? Unduh jawaban Google Form terbaru, impor lewat tab Data Kader, lalu ulangi langkah 2–3.
